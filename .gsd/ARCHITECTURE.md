## Data Flow

1. User inputs a transcript (or uses a demo snippet).
2. The UI calls `/api/generate` with the transcript payload.
3. The API route verifies rate limits, validates schema, and invokes the pipeline logic.
4. The pipeline uses Gemini API to produce a structured product spec.
5. Structured JSON is returned to the client and rendered in the UI with interactive highlights.
