# VoiceSpec Demo Script

**Duration**: 2 Minutes

## [0:00 - 0:30] Introduction & Problem

_(Screen is showing the Wispr Flow or the VoiceSpec landing page)_

**Speaker:**
"Hi, I'm excited to show you VoiceSpec. As product managers and engineers, we spend hours turning raw discovery calls or quick dictations into structured, developer-ready specifications. It's tedious, and we often lose the original context—the _why_ behind a task. VoiceSpec solves this by generating structured specs instantly, with full provenance back to the original transcript."

## [0:30 - 1:00] Demonstration & Generation

_(Action: Click 'Use an example' to load the sample transcript, or paste a dictation, then click 'Generate spec')_

**Speaker:**
"Here we have a raw dictation from a product meeting. Watch as I click Generate. VoiceSpec streams stage events, processes the text, and normalizes it. Behind the scenes, it routes the text through Google Gemini. Notice how fast and seamless the generation is—it handles rate limits and capacity transparently, switching to a fallback model if necessary."

## [1:00 - 1:30] Highlighting Provenance

_(Action: Click on a generated task or requirement. The UI highlights the exact sentence in the transcript)_

**Speaker:**
"The spec is ready. But here's the killer feature: Provenance. When I click on this new task, VoiceSpec highlights the exact sentence in the original transcript that inspired it. You never have to guess where a requirement came from. Every item is fully grounded."

## [1:30 - 2:00] Export & Conclusion

_(Action: Open the Export dropdown and show the options)_

**Speaker:**
"Once you're happy with the spec, it's immediately actionable. You can export the entire spec as Markdown, copy an Agent Prompt with a topologically sorted task list ready for an AI coding agent, or generate a GitHub CLI script to instantly file these tasks as issues. VoiceSpec turns rambling into reality. Thank you!"
